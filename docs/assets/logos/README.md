# Logos

Single-color brand marks from [Simple Icons](https://simpleicons.org) (CC0), colored with each brand's own color. The logos are trademarks of their owners (Google, Doist, GitHub, Atlassian) and appear on the site only to show which tools Lobot works with. To use a vendor's official full-color file instead, replace the SVG with one from that vendor's brand page and keep the file name.
