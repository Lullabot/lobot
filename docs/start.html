Get started

Get Lobot running on your project.

No command line required. You make a folder and paste a prompt; your assistant does the technical setup, explains each step in plain language, and stops to ask when it needs you.

Before you start

Three things to have ready.

An AI assistant

One that can work in a folder on your computer. Claude Cowork is the easiest; Claude Code, Codex, Cursor, Gemini CLI, and OpenCode work too.

A GitHub account

Lobot saves your project to a private GitHub repository. The assistant walks you through making the access key it needs.

The project basics

The project's name, a short project key (like EXU), and its code repository, if it has one.

Pick your path

Starting fresh, or joining in?

Make an empty folder for the project, connect it to your assistant (in Claude Cowork, add the folder to the session), and paste the prompt that fits.

Starting a new project

You're the first PM to use Lobot on this project.

New project prompt
## Goal
Set up a new Lobot Project Brain in this folder. Lobot: https://github.com/Lullabot/lobot

## What I'll do
- Give you the project's name, a short project key (like EXU), and its code repository.
- Create a GitHub token when you walk me through it, and paste it only where you tell me, never into this chat.
- Approve anything other people will see, like creating the GitHub repository.

## What you'll do
1. Check that Node 18 or later is installed, and help me install it if it isn't.
2. Install Lobot here with: npx --yes github:Lullabot/lobot init --name "<name>" --key <KEY>
3. Clone the code repository into repo/.
4. Read the new CLAUDE.md, then follow the project-setup skill to put this Project Brain on GitHub.
5. If I'm using Claude Cowork, tell me what to paste into my Cowork project's instructions.

## How
Do the terminal work for me, explain what's happening in plain language, and stop to ask when you need me.

Joining or taking over a project

The project already has a Project Brain on GitHub (its name ends in -pm).

Join prompt
## Goal
Join a project whose Project Brain is already on GitHub, and set it up in this folder.

## What I'll do
- Tell you the Project Brain's repository (it ends in -pm, like Lullabot/example-site-pm).
- Create a GitHub token when you walk me through it, and paste it only where you tell me, never into this chat.
- Approve anything other people will see.

## What you'll do
1. Read the project-setup skill: https://github.com/Lullabot/lobot/blob/main/engine/skills/project-setup/SKILL.md
2. Follow its "Join a project" section to bring the Project Brain into this folder and set up what it leaves out.
3. If I'm using Claude Cowork, tell me what to paste into my Cowork project's instructions.
4. Run the start-of-session routine and catch me up on the project.

## How
Do the terminal work for me, explain what's happening in plain language, and stop to ask when you need me.
What happens next

Your assistant takes it from here.

It checks your computer

It installs the few tools Lobot needs (Node, Python, and GitHub's tool). You don't need to know what they are.

It asks for the details

The project's name and key, and its code repository. It walks you through making a GitHub access key, which you paste only where it tells you, never into the chat.

It saves and catches you up

Lobot moves in, the project is saved to its private repository with your approval, and you're ready for your first question.

Your first day

Talk to it like a project coordinator.

Good morning. Where are we?

Lobot catches you up and opens your dashboard for the day.

Process today's meeting with the client.

Lucy writes the notes and proposes the decisions, risks, and action items for your approval.

Wrap up.

Lobot closes out the day's journal, so tomorrow starts with an accurate picture.

When you get stuck

Just say what happened.

Describe it in plain words

Tell your assistant what you saw or what went wrong. It knows Lobot's setup and can usually fix it for you.

Already set up?

Tell your assistant "update Lobot" to get the latest version.

Something's off with Lobot?

Ask your assistant to send feedback to Lobot. It drafts the report without project details, and you approve it first.
