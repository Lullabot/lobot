Get Started

Get Lobot Running on Your Project.

Start with a folder and a prompt. Your AI agent does the technical work, explains each step in plain language, and stops to ask when it needs you.

All You Need

A Folder and an AI Agent.

Required

An AI agent that can edit files in a folder on your computer, and an empty folder. Lobot works with any of them, for example Claude, Codex, Cursor, Gemini CLI, or OpenCode.

Recommended

Connect your AI agent to Google Drive, Docs, and Sheets, so it can find meeting transcripts and keep project Docs and Sheets current.

Optional

A GitHub account, for a backup, a history of every change, and sharing the project with another PM. You can add it any time. Back up to GitHub

Start a New Project

Up and Running, No Git Required.

Everything stays in the folder on your computer. Add GitHub later, when you want a backup or a teammate.

  1. Make a Folder

    Create an empty folder for the project, for example Documents/Projects/acme-pm.

    mkdir -p ~/Projects/acme-pm

  2. Give Your AI Agent Access

    Give your AI agent access to edit files in the folder: open the folder in it, or add the folder to a project there. If it asks whether to allow access once or always, allow it for this project only.

  3. Paste the Prompt

    Copy it into your AI agent and send it. It says how comfortable you are with Git, so Lobot pitches its instructions at your level.

    New Project Prompt
    ## Goal
Set up a new Lobot Project Brain in this folder. Lobot: https://github.com/Lullabot/lobot

## What I'll do
- Give you the project's name and a short project key (like EXU).
- Tell you I'm new to Git and the terminal, so walk me through anything I have to do myself.Tell you I've used GitHub (GitHub Desktop) but not the terminal, so give me short steps.Tell you I'm comfortable with git and the terminal, so just give me the commands.
- Approve anything other people will see.

## What you'll do
1. Check that Node 18 or later is installed, and help me install it if it isn't.
2. Install Lobot here with: npx --yes github:Lullabot/lobot init --name "<name>" --key <KEY>
3. Read the new CLAUDE.md and save my comfort with Git and the terminal (pm-profile skill).
4. Skip GitHub for now. Keep everything in this folder and remind me later.
5. If you keep standing instructions for this project, tell me what to add to them.

## How
Do the terminal work for me, explain what's happening in plain language, and stop to ask when you need me.

    Or install it yourself: npx --yes github:Lullabot/lobot init --name "Acme" --key ACM, then ask your AI agent to read CLAUDE.md.

  4. Answer Its Questions

    The project's name, a short key, and what you'd like Lobot to keep track of. "Not yet" is a fine answer.

  5. Connect the Tools You Use

    In your AI agent's connector or integration settings, connect the tools your project runs on. Lobot works with Google Drive, Docs, and Sheets for sharing files, and Todoist for managing your tasks. Then start a new chat, so your AI agent sees them. See all integrations

  6. Try It

    Say Process my last meeting. Lobot finds the transcript (in Google Drive if you connected it, or a file you drop into the folder), writes the notes, and asks you to approve what it found.

When you're ready: back up to GitHub
Use Files You Already Have

Bring an Existing Folder Along.

Lobot can't be installed straight into a folder that already has files yet. Until it can, give it a folder of its own and let it read yours.

  1. Make a New, Empty Folder for Lobot

    Put it next to your existing folder, not inside it.

  2. Give Your AI Agent Access to Both

    It edits files in the new folder and only reads the old one.

  3. Paste the New Project Prompt

    The same prompt as Start a new project, in the new folder.

  4. Ask for an Inventory

    Say Take an inventory of my folder <name>. Read it, don't change it. Lobot builds the project overview, people, glossary, and open questions from what it finds, citing each file.

Is the existing folder a code repository? Ask Lobot to clone it into the Project Brain's repo/ folder instead, where it's read but never changed.

Join or Share a Project

Anyone With the Repository Can Pick It Up.

A Project Brain is a Git repository on GitHub. Anyone with access can get a copy and work on it with any AI agent. Sharing one needs GitHub.

To Share Yours

  1. Make sure the project is backed up to GitHub.
  2. Invite them: on GitHub, open the repository, then Settings › Collaborators › Add people. They need their own GitHub account.
  3. Send them this page.

To Join One

  1. Accept the invitation while signed in to GitHub.
  2. Make an empty folder and give your AI agent access to edit files in it. Lobot copies the project into it for you.In GitHub Desktop, choose File › Clone repository, pick the repository ending in -pm, and put it in its own folder. Give your AI agent access to edit files in that folder.gh repo clone Lullabot/<project>-pm, then give your AI agent access to edit files in the folder.
  3. Paste the join prompt.

Back up to GitHub

Add GitHub When You're Ready.

A Backup

Your project lives somewhere besides your laptop.

A History

Lobot saves each piece of work as its own change, labeled with what it did and where it came from.

A Way to Share

Another PM can join or take over and pick up exactly where you left off.

  1. Create a GitHub Account

    Sign up at github.com with your work email. Use your own account; there's no separate company account. Turn on two-factor sign-in (Settings › Password and authentication) and save the recovery codes. Your organization may require it.

  2. Install GitHub Desktop

    Download it from desktop.github.com and sign in. It's how you'll send your work up to GitHub.

  3. Ask Lobot to Set It Up

    Say Set up GitHub for this project. Lobot walks you through an access key (you paste it only where it says, never into the chat) and creates a private repository for the project.

  4. Send Your Work Up

    Lobot saves your work as it goes, but some AI agents can't send it to GitHub themselves. When Lobot says work is waiting, open GitHub Desktop, choose your project's folder, and click Push origin (the first time, Publish branch).

  1. GitHub account on your work email, with two-factor sign-in on.

  2. GitHub Desktop (or your git app), signed in.

  3. Tell Lobot Set up GitHub for this project. It creates a private repository named after the code repository plus -pm.

  4. If your AI agent can't push, push from GitHub Desktop when Lobot says commits are waiting.

gh auth login
gh repo create Lullabot/<code-repo>-pm --private --source . --remote origin --push

# later, if your AI agent can't push Lobot's commits itself:
git push

Or tell Lobot Set up GitHub for this project. and it runs these for you where your AI agent allows.

Can't create the repository (your account isn't in the organization yet)? Keep working: Lobot saves everything in the folder and reminds you. Until then, make sure Time Machine or similar backs the folder up.

Troubleshooting

Common Snags.

A GitHub invitation link shows "404 Not Found"
You're signed out. Sign in to GitHub, then open the link again.
GitHub asks for two-factor sign-in
Your organization requires it. Use an authenticator app, and save the recovery codes somewhere safe.
Your AI agent can't see a folder you just added
Start a new chat. A session only sees the folders it started with.
Asked to allow a folder "once" or "always"
Allow it for this project. "Always" opens the folder to every project.
Lobot says it can't push
Your AI agent blocks it. Push from GitHub Desktop (or git push).
GitHub Desktop shows a folder inside a folder
Choose the project's top folder, the one with CLAUDE.md in it.
Your AI agent can read a Google Doc or Sheet but not edit it
Some AI agents connect Google Drive, Docs, and Sheets separately, and Drive alone can only read and create files. Connect Docs and Sheets too.
Something else
Tell your AI agent what you saw, in plain words. It knows Lobot's setup and can usually fix it. Already set up? Say "update Lobot" to get the latest version.
